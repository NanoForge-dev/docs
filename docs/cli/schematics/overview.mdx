## What are schematics?

Schematics are the templates that write the files of a NanoForge project. They are built on
[Angular DevKit schematics](https://github.com/angular/angular-cli/tree/main/packages/angular_devkit/schematics)
and ship in the `@nanoforge-dev/schematics` package.

You normally use them through the CLI:

| Command                                     | Schematics it runs                                                   |
| ------------------------------------------- | -------------------------------------------------------------------- |
| [`nf new`](/docs/cli/commands/new)                 | `project` alone, or `workspace` then `project` twice with `--server` |
| [`nf create component`](/docs/cli/commands/create) | `component`                                                          |
| [`nf create system`](/docs/cli/commands/create)    | `system`                                                             |
| [`nf create plugin`](/docs/cli/commands/create)    | `plugin`                                                             |

These pages list each schematic's options and the files it writes, so you know what you get and
what you can change.

## Running a schematic without the CLI

The CLI already includes the schematics. To run one by hand, install the schematics CLI and the
package, then call it with its options:

```bash
npm install -g @angular-devkit/schematics-cli
npm install @nanoforge-dev/schematics
schematics @nanoforge-dev/schematics:<schematic> [--option=value ...]
```
