NanoForge is a game engine for the web browser, built around an ECS (entities, components, systems), with a CLI to create, run and ship games and a visual editor.

## How this site is made

Each page belongs to the repository of the product it documents (`engine`, `cli`, `loader`, `editor`), in its `docs/docs` folder. Every release of that repository copies its pages here, and the API reference is generated from the engine's TSDoc comments.

Found a mistake? Open an issue or a pull request in the repository of that product.
