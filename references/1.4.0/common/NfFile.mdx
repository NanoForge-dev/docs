## Remarks

  Instances are returned by `AssetManagerLibrary.getAsset`. Each method lazily fetches the file from the engine&#39;s virtual file system and returns the content in the requested format.  All read methods throw `NfFetchException` when the underlying `fetch` returns a non-OK response.
