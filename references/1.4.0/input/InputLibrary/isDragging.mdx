# isDragging

## Summary

Return whether a drag operation is in progress.  
## Signature

```typescript
isDragging(button?: InputEnum): boolean;
```

## Parameters

### button
**Type**:<RefLink target="input.InputEnum">`InputEnum`</RefLink>
**Optional**: Yes

If provided, only returns true when a drag was started with this specific button.

## Returns

**Type**:`boolean`

Return whether a drag operation is in progress.
