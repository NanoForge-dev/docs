# useGraphics

## Summary

Register the graphics library used to render the game.  
## Signature

```typescript
useGraphics(library: IGraphicsLibrary): void;
```

## Parameters

### library
**Type**:`IGraphicsLibrary`

Graphics library instance (e.g. Graphics2DLibrary).

## Returns

**Type**:`void`

Register the graphics library used to render the game.
