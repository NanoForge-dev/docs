# BaseInputLibrary

## Summary

Abstract base class for input libraries.  
## Signature

```typescript
declare abstract class BaseInputLibrary extends Library implements IInputLibrary 
```

## Remarks

  Extend this class to implement a custom input back-end and register it with `NanoforgeClient.useInput`. The built-in implementation is `InputLibrary`.
