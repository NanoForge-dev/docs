# constructor

## Summary

Constructs a new instance of the `InitContext` class  
## Signature

```typescript
constructor(context: ApplicationContext, libraryManager: LibraryManager, configRegistry: IConfigRegistry, options: IRunOptions);
```

## Parameters

### context
- **Type**:<RefLink target="common.ApplicationContext">`ApplicationContext`</RefLink>

Shared application-level runtime state.

### libraryManager
- **Type**:<RefLink target="common.LibraryManager">`LibraryManager`</RefLink>

Manager giving access to other registered libraries.

### configRegistry
- **Type**:<RefLink target="common.IConfigRegistry">`IConfigRegistry`</RefLink>

Registry used to resolve typed configuration objects.

### options
- **Type**:<RefLink target="common.IRunOptions">`IRunOptions`</RefLink>

Run options forwarded from NanoforgeApplication.init.
