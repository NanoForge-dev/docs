## Remarks

  Loads a compiled `libecs.wasm` binary via the asset manager and initialises a `Registry` from the resulting module. Concrete subclasses only need to set `this.path` (the asset path to the `.wasm` file) and call `super()` — see `ECSClientLibrary` and `ECSServerLibrary`.  Requires the `ASSET_MANAGER_LIBRARY` dependency and runs after `GRAPHICS_LIBRARY`.
