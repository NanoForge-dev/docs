> **EditorRunState** = `"running"` \| `"paused"` \| `"stopped"`

Defined in: [modules/editor/src/protocol.ts:108](https://github.com/NanoForge-dev/Engine/blob/ed8c7e0b33d17f8343c32659cf63ba4166a4fa53/modules/editor/src/protocol.ts#L108)

- `running` / `paused`: the loop is ticking (paused ticks only drain events).
- `stopped`: every library was cleared and the viewport disposed.
